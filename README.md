# 42 Net_Practice

## Description

This project is an introduction to computer networking, built around a training interface provided by 42.

The interface offers 10 levels of increasing difficulty. Each level shows a network topology with broken configurations (IP addresses, subnet masks, default gateways, routing rules). The goal is to fix every device so that all of them can communicate according to the objectives of the level.

Along the way, the project covers TCP/IP addressing, subnetting, routers, switches, and the OSI model.

## Instructions

### Requirements

- Linux or WSL (Ubuntu) with a web browser.
- The training interface files provided by 42, including `run.sh`.

### Execution

```sh
./run.sh
```

If the script is not executable:

```sh
chmod +x run.sh
```

Then open the address shown by the script in your browser, pick a level, and edit the configuration of each device until all the goals are met.
